Веб-сервис для прогнозирования энергопотребления сталелитейного предприятия на основе машинного обучения.
📋 О проекте
    Проект представляет собой интеллектуальную систему, 
    которая позволяет инженерам и аналитикам предсказывать потребление электроэнергии (kWh) 
    на основе технических параметров мощности и временных факторов.

Ключевые возможности:
ML Прогноз: 
    Использование модели Random Forest для высокоточных расчетов.
Доверительные интервалы: 
    Вывод результата с учетом погрешности ($\pm 5\%$).
История запросов: 
    Автоматическое сохранение всех расчетов в базу данных.
Личный кабинет: 
    Система регистрации и авторизации пользователей.
    
🛠 Технологический стек
Backend: Django 5.x
Machine Learning: Scikit-learn, Pandas, NumPy
Model Storage: Joblib
Database: SQLite3
Frontend: HTML5, CSS3 (Custom Dark Theme)

📊 Описание модели
Модель обучена на открытом датасете энергопотребления сталелитейной промышленности.
Алгоритм: 
    RandomForestRegressor
Метрики качества: 
    MAE: 6.07, 
    RMSE: 11.97
Признаки (Features):
    NSM — количество секунд с начала суток.
    Lagging/Leading Power Factor — показатели мощности.
    Load_Type — тип нагрузки.
    DayOfWeek — день недели.

🚀 Как запустить проект локально
Клонируйте репозиторий:
    git clone https://github.com/ваш-логин/ваш-репозиторий.git
    cd ваш-репозиторий

Создайте виртуальное окружение:
    python -m venv venv
    source venv/bin/activate  # Для Linux/macOS
    # или
    venv\Scripts\activate     # Для Windows

Установите зависимости:
    pip install -r requirements.txt

Примените миграции:
    python manage.py makemigrations
    python manage.py migrate

Запустите сервер:
    python manage.py runserver
Откройте браузер:
    Перейдите по адресу http://127.0.0.1:8000/
